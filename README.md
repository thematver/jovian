# Jovian-8

Полифонический синтезатор в духе Roland Jupiter-8 в формате **Audio Unit v3** для Logic Pro
(и любого AU-хоста на macOS 14+), написанный на Swift. Пресеты совместимы с **Arturia Jup-8 V4**
в обе стороны.

> Jupiter-8 — торговая марка Roland, Jup-8 V — Arturia. Проект с ними не связан и не содержит их кода
> или пресетов: заводские пресеты Arturia читаются с диска пользователя, если Jup-8 V установлен.

## Установка

```bash
Tools/install.sh
```

Скрипт генерирует Xcode-проект (Tuist), собирает `Jovian8.app` с расширением `Jovian8AU.appex`,
кладёт его в `~/Applications` и регистрирует Audio Unit. В Logic: *Instrument → AU Instruments →
Jovian → Jovian-8* (если не появился — *Settings → Plug-in Manager → Reset & Rescan Selection*).

Проверка: `auval -v aumu JV8e Jovn`.

## Что внутри

| Часть | Где |
|---|---|
| DSP-движок: 2 VCO (sync, cross-mod, PWM), HPF, 4-полюсный фильтр с 12/24 dB, 2 ADSR, LFO, VCA, 16 голосов, Solo/Unison/Poly 1/Poly 2, арпеджиатор, портаменто, бендер, колесо модуляции, «дисперсия» голосов, 2× передискретизация | `Sources/Jovian8Core/DSP` |
| Надстройки Jup-8 V: LFO 2/3, матрица модуляции (velocity, aftertouch, key track, mod wheel, MPE slide), кривые клавиатуры, 3 слота FX (Reverb, Delay, Chorus, Flanger, Phaser, Overdrive, Compressor, BitCrusher, Filter, Param EQ, Stereo Pan) | `DSP/Modulation.swift`, `FX/` |
| Параметры: 419 штук, id = ключи пресетов Jup-8 V, те же нормализованные значения и кривые | `Params/` (генерируется `Tools/gen_params.py`) |
| Формат пресетов Jup-8 V (Boost text archive) и экспорт `.jup4x` | `Preset/` |
| AUv3 + интерфейс (Panel / Modulation / Effects / Presets) | `Xcode/AU` |
| Приложение-контейнер с пакетным конвертером | `Xcode/App` |
| CLI: рендер в WAV, просмотр и конвертация пресетов | `Sources/jovian8` |

## Совместимость пресетов

* **Jup-8 V → Jovian-8.** Вкладка *Presets* показывает заводские и пользовательские пресеты из
  `/Library/Arturia/Presets/Jup-8 V4`, а также `.jup4x`, брошенные в `~/Music/Jovian-8`. Файлы можно
  перетащить прямо в окно плагина.
* **Jovian-8 → Jup-8 V.** *Export to Jup-8 V* пишет `~/Music/Jovian-8/Exports/<имя>.jup4x`; в Jup-8 V:
  браузер пресетов → *Import*.
* Параметры, которые Jovian-8 не воспроизводит (секвенсор, Mod Mixer, макросы, MIDI-назначения),
  сохраняются в состоянии плагина и возвращаются при экспорте без изменений.
* Проверено: все 341 пресет из установленного Jup-8 V проходят цикл «чтение → состояние → запись →
  чтение» без потерь (ошибка ≤ 5·10⁻⁸); 333 из них после перезаписи совпадают с оригиналом байт в
  байт (остальные 8 — двухтембровые пресеты со вложенными заголовками).

## Как подбиралось звучание

Значения в пресетах нормализованы (0…1), поэтому важно, чтобы движок понимал их так же, как
Jup-8 V. Кривые параметров сверены с отображаемыми значениями оригинального плагина; поведение,
которое на экран не выводится (частота среза, резонанс, глубины модуляции, огибающие, sync,
cross-mod, громкость), измерено офлайн-рендером Jup-8 V и анализом спектра. Результаты — в
`DSP/VoiceMath.swift`. На случайной выборке заводских пресетов (FX выключены в обоих) громкость
совпадает в среднем до ~1 dB; спектральный баланс отличается в среднем на ~5 dB по третьоктавам
(биения осцилляторов и случайные фазы дают заметную часть разницы).

## Ограничения

* Секвенсор нот/модуляции и Mod Mixer Jup-8 V не воспроизводятся (данные сохраняются).
* Режимы Dual/Split Jup-8 V не поддерживаются.
* FX эмулированы по описанию параметров, без побайтовой сверки с оригиналом.
* Импорт `.jup4x` в Jup-8 V проверен на уровне формата файла (писатель совпадает с Arturia байт в
  байт), но не через само окно Jup-8 V: имя корневой папки в архиве (`Jup-8/User/...`) выведено по
  аналогии с другими продуктами Arturia.

## Разработка

```bash
swift test                 # 22 теста: кривые, формат пресетов, FX
swift build -c release
.build/release/jovian8 roundtrip
.build/release/jovian8 render "/Library/Arturia/Presets/Jup-8 V4/Factory/Factory/Jupiter Bass" out.wav
```
