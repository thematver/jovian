# Jovian-8

Полифонический синтезатор в духе Roland Jupiter-8. Пресеты в обе стороны совместимы с **Arturia Jup-8 V4**.
Написан на Rust и собирается в три формата:

| Формат | Где после установки | Для чего |
|---|---|---|
| **AU** (Audio Unit v2) | `~/Library/Audio/Plug-Ins/Components/Jovian-8.component` | Logic Pro, GarageBand, MainStage |
| **VST3** | `~/Library/Audio/Plug-Ins/VST3/Jovian-8.vst3` | Ableton Live, Cubase, Reaper, Studio One |
| **CLAP** | `~/Library/Audio/Plug-Ins/CLAP/Jovian-8.clap` | Bitwig, Reaper |

> Jupiter-8 — торговая марка Roland, Jup-8 V — Arturia. Проект с ними не связан и не содержит их кода
> или пресетов: заводские пресеты Arturia читаются с диска пользователя, если Jup-8 V установлен.

## Сборка и установка

```bash
Tools/build.sh           # собрать и поставить все три формата
Tools/build.sh --check   # то же + auval
```

Нужны Rust (rustup), CMake и Ninja (`brew install cmake ninja`). Скрипт сам скачивает
clap-wrapper на закреплённом коммите и накладывает `au/clap-wrapper.patch`. В Logic после первой
установки: *Settings → Plug-in Manager → Reset & Rescan Selection* (или перезапуск Logic).
Инструмент: *Instrument → AU Instruments → Jovian → Jovian-8*.

## Интерфейс

Векторная панель, нарисованная собственным рендером (tiny-skia + встроенные OFL-шрифты Barlow и
JetBrains Mono): Retina, масштаб 75–150 % (кнопка `100%` в правом верхнем углу).

* **SYNTH** — панель Jupiter-8: LFO, VCO MOD, PWM, VCO-1/2, микшер/HPF, VCF, VCA, две огибающие;
  слева MASTER, ASSIGN, ARPEGGIO; снизу бендер, колесо модуляции и клавиатура (играет мышью).
* **MOD** — LFO 2/3 с живым превью формы, матрица модуляции, редактируемые кривые клавиатуры,
  дисперсия голосов.
* **EFFECTS** — три слота, последовательно или параллельно; у каждого эффекта своя живая картинка
  (АЧХ эквалайзера с перетаскиваемыми узлами, фильтр, кривая компрессора и индикатор подавления,
  отводы дилея, хвост реверба, LFO модуляционных эффектов).
* **LIBRARY** — все пресеты Jovian-8, Jup-8 V и свои; типы, избранное, поиск (можно просто начать
  печатать), стрелки ↑/↓ листают пресеты. «Save to My Presets» пишет `.jup4x` в `~/Music/Jovian-8`.

Дисплей в шапке показывает параметр, которого касаетесь, и его график: АЧХ фильтра, форму огибающей,
волну LFO. В покое на нём голоса, лампа LFO и уровни огибающих.

Жесты: перетаскивание (Shift — точно), двойной клик или ⌘-клик сбрасывает к значению по умолчанию,
колесо мыши меняет значение. Клик по треку фейдера переносит ползунок туда, как на железе.
Элементы, которые в текущем режиме ни на что не влияют (например, DIVISION при свободном клоке),
приглушаются.

## Совместимость пресетов

* **Jup-8 V → Jovian-8.** Библиотека показывает пресеты из `/Library/Arturia/Presets/Jup-8 V4` и
  любые `.jup4x` / файлы пресетов из `~/Music/Jovian-8`. Файлы можно перетащить в окно или открыть
  кнопкой *Import…*.
* **Jovian-8 → Jup-8 V.** Сохранённые `.jup4x` импортируются в Jup-8 V через его браузер (*Import*).
* Параметры, которые Jovian-8 не воспроизводит (секвенсор, Mod Mixer, макросы, MIDI-назначения),
  хранятся в состоянии плагина и возвращаются при экспорте без изменений.
* Проверено: все 341 пресет установленного Jup-8 V проходят цикл «чтение → состояние → запись →
  чтение» без потерь; 333 из них после перезаписи совпадают с оригиналом байт в байт (остальные 8 —
  двухтембровые с вложенными заголовками).

## Устройство

| Каталог | Что там |
|---|---|
| `crates/core` | параметры (419, id = ключи пресетов Jup-8 V), DSP-движок, эффекты, формат пресетов |
| `crates/gui` | интерфейс: рендер, шрифты, виджеты, страницы; не зависит от плагинного API |
| `crates/plugin` | nih-plug: CLAP + VST3, окно (baseview + softbuffer), связь интерфейса с хостом |
| `crates/cli` | `jovian8`: рендер в WAV, сравнение, проверка пресетов |
| `au/` | CMake-проект AUv2 на clap-wrapper и патч к нему |
| `swift/` | исходная реализация на Swift (AUv3) — эталон звука |
| `Tools/` | сборка, генератор таблицы параметров, тестовые AU-хосты |

Rust-движок — перенос Swift-версии один в один: рендеры всех 319 заводских пресетов отличаются от
Swift не больше чем на −103 dB от сигнала.

### Исправления в clap-wrapper (`au/clap-wrapper.patch`)

* `kAudioUnitProperty_ParameterStringFromValue` с `inValue == NULL` (запрос текущего значения,
  разрешён спецификацией) разыменовывал NULL и ронял хост.
* Изменения параметров из окна плагина не доходили до плагина, пока хост не обрабатывал звук:
  AUv2-обёртка игнорировала `request_flush`. Теперь флаш выполняется из таймера окна в главном
  потоке, а изменения уходят хосту как жесты автоматизации.

## Разработка

```bash
cargo test -p jovian-core --release                 # кривые, форматы, DSP-примитивы
target/release/jovian8 roundtrip                    # все пресеты Jup-8 V
target/release/jovian8 render "<пресет>" out.wav    # офлайн-рендер ядром
target/release/jovian-shot build/shots [пресет]     # PNG всех страниц интерфейса
Tools/auhost/auhost build/auhost script.txt         # открыть AU-окно, кликать, снимать кадры
Tools/aurender/aurender out.wav                     # офлайн-рендер через установленный AU
```

`Tools/gen_params.py` генерирует таблицу параметров (Rust и Swift) из определений установленного
Jup-8 V.

## Ограничения

* Секвенсор нот/модуляции и Mod Mixer Jup-8 V не воспроизводятся (данные сохраняются).
* Режимы Dual/Split Jup-8 V не поддерживаются.
* Эффекты эмулированы по описанию параметров, без побайтовой сверки с оригиналом.
* Проекты Logic, сохранённые со старой AUv3-версией (1.0), откроются с новой версией, но настройки
  патча в них не перенесутся — форматы состояния разные.
